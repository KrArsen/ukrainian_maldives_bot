# 🌴 Telegram Бот Бронювання — «Українські Мальдіви» 🌊

Повнофункціональний, спрощений Telegram-бот для автоматизації процесу онлайн-бронювання шатер (бунгало) в відпочинковому комплексі «Українські Мальдіви».

---

## 🛠️ Стек технологій

- **Python 3.11+**
- **aiogram 3.13** (асинхронна робота з Telegram Bot API)
- **SQLite + aiosqlite** (локальна база даних, що не потребує окремого сервера)
- **SQLAlchemy 2.0 (async)** (асинхронна ORM)
- **APScheduler** (планувальник задач та автоматичні нагадування)
- **python-dotenv** / **pydantic-settings** (зчитування конфігурації з .env)

---

## 🚀 Інструкція із встановлення та запуску

### 1. Підготовка оточення
Створіть віртуальне середовище Python та встановіть залежності:

```bash
# Перейдіть до папки проекту
cd ukrainski_maldivi_bot

# Створіть віртуальне оточення
python -m venv venv

# Активуйте віртуальне оточення
# На Windows:
venv\Scripts\activate
# На macOS/Linux:
source venv/bin/activate

# Встановіть залежності
pip install -r requirements.txt
```

### 2. Налаштування файлу `.env`
Скопіюйте шаблон налаштувань:

```bash
cp .env.example .env
```

Відкрийте файл `.env` та заповніть наступні поля:
- `BOT_TOKEN`: Отримайте токен бота у [@BotFather](https://t.me/BotFather).
- `ADMIN_IDS`: Ваші Telegram ID (числова послідовність) для доступу до адмін-панелі. Кілька ID вказуйте через кому, наприклад: `8796624309,987654321`.

### 3. Налаштування команд бота в BotFather
Знайдіть свого бота в BotFather та встановіть меню команд через `/setcommands`:
```
start - Головне меню
booking - Забронювати
mybookings - Мої бронювання
admin - Панель адміна
```

### 4. Запуск Бота
Запустіть бота командою:

```bash
python -m bot.main
```
База даних `bot.db` буде створена автоматично в корені проекту при першому запуску!

## 💡 Функціонал бота

### Клієнтська частина (User-side)
1. **Головне меню**: Persistent reply-меню з кнопками «📅 Забронювати», «📋 Мої бронювання» та «📞 Контакти».
2. **Процес бронювання (FSM)**:
   - Крок 1: Вибір одного з 10 однакових шатер (Шатро №1 ... Шатро №10).
   - Крок 2: Вибір конкретної дати (на 1 ніч) через inline-календар. Дати, на які всі 10 шатер повністю зайняті, підсвічуються як ❌.
   - Крок 3: Введення імені та прізвища текстом.
   - Крок 4: Введення контактного телефону за допомогою кнопки «📱 Поділитись номером».
   - Крок 5: Підтвердження деталей замовлення (фіксовано на 2 дорослих).
3. **Мої бронювання**: Перегляд історії власних бронювань із поточними статусами (Очікує / Підтверджено / Скасовано).

### Панель адміністратора (Admin-side)
Доступ за командою `/admin` або кнопкою для користувачів з `ADMIN_IDS`.
1. **🔔 Нові заявки**: Перегляд заявок у статусі `pending`. Можливість **підтвердити** (клієнт отримає сповіщення) чи **скасувати** (із введенням текстової причини скасування).
2. **📅 На сьогодні / На завтра**: Перегляд зайнятих та вільних шатер на обрану дату.
3. **📋 Всі бронювання**: Пагінований перегляд останніх 50 замовлень з бази.

### Автоматичні задачі (Scheduler)
1. **Щоденний звіт адмінам**: Щодня о 09:00 надсилає адмінам звіт зі списком заїздів на сьогодні та вільними шатрами.
2. **Нагадування про заїзд**: Щодня о 18:00 надсилає нагадування користувачам, у яких заїзд завтра.
